DATA-DRIVEN AI FUNCTIONS

데이터 기반 AI 기능

각 기능은 같은 ‘AI’가 아니라 입력, 모델, 출력과 서비스 사용 지점이 다릅니다.

RETRIEVAL / GENERATION

경매 ROI 리포트

문서 근거와 작품 이미지, 가격·입찰 신호를 결합해 경매 전략과 예상 시나리오를 설명합니다.

INPUT
PDF · 이미지 · 가격 · 반응
ENGINE
RAG-Anything · LightRAG · LLM
OUTPUT
근거 포함 경매 분석 리포트
PREDICTION

조회수·인기 분류

작품 반응, 비율, 품질, 시간 피처를 이용해 예상 조회수와 고조회수 확률을 계산합니다.

INPUT
조회 · 좋아요 · 댓글 · 시간 피처
ENGINE
RandomForest 회귀·분류
OUTPUT
예측값 · 확률 · threshold 판정
RECOMMENDATION

작품·예술관 추천

제목·카테고리·설명·태그를 텍스트 특징으로 만들고 유사도가 높은 후보를 반환합니다.

INPUT
작품 설명 · 태그 · 갤러리 문맥
ENGINE
TF-IDF · Cosine Similarity
OUTPUT
추천 ID · 유사도 점수
MULTIMODAL

이미지 생성·분석

프롬프트로 작품 이미지를 생성하고 S3 저장 경로와 이미지 분석 결과를 서비스 데이터로 연결하는 흐름입니다.

INPUT
Prompt · 작품 메타데이터
ENGINE
Image Generation · Vision
OUTPUT
S3 URL · 제목 · 설명

IMPLEMENTATION SCOPE

제가 설명할 수 있는 범위

작품·예술관 CRUD, 경매·결제, AWS S3 저장은 Spring Boot 중심으로 직접 구현했습니다. AI 기능은 생성형 AI 도구와 팀의 기존 모델을 활용했으며, 입력 데이터와 모델 목적, FastAPI 요청·응답 계약, Spring Boot 연결 로직과 실패 흐름을 코드 기준으로 검토하고 이해했습니다.
